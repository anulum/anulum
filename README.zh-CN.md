# Miroslav Šotek

我是常驻瑞士的独立研究人员与系统工程师，以 Anulum 名义开发科学软件及受治理的研究组织。五个活跃组覆盖反应堆系统、集成与控制、智能体协调与保障、神经形态计算以及量子计算。第六组 Scientific Discovery and Experimentation 正在组建。已发布软件、架构工作、世界模型开发及预期硬件产出各有独立的证据边界。我们寻求与伙伴共同成立研究所和公司。

**主要实现：** Python、Rust、TypeScript、JavaScript 和 Go。

**硬件、Web 与运维：** Verilog、SystemVerilog、WGSL/WebGPU、HTML/CSS、
Shell、Docker 和 Linux。

## 证据，而非口号

真实的负面结果和零结果会被公开。公开主张始终绑定到测量、运行前提交的协议、
原始结果包或可执行验证等工件，而不是口号。

示例：[scpn-quantum-control](https://github.com/anulum/scpn-quantum-control)
中运行前提交的量子控制协议与哈希绑定结果包。

## 工作原则

- 证据先于主张。
- 可复现工件先于展示。
- 明确区分研究、验证和产品就绪度。
- 在性能或硬件集成确有需要时采用跨语言实现。
- 如实记录失败：负面结果也是研究产出的一部分。
